# Artwork Metadata Template

Use this template when adding a new artwork or collection.

```yaml
title:
year:
collection:
medium:
category:
status: finished
description:
images:
  - filename:
    type: finished
  - filename:
    type: process
```

## Suggested categories

- Drawing
- Painting
- Clay Sculpture
- Craft
- Model
- Mixed Media
- Digital Art

## Image types

- `finished` — completed artwork
- `process` — making / work in progress
- `detail` — close-up of an important detail
- `artist` — creator with the artwork
