# Ganesh Chaturthi 2026

## Collection theme

**From Drawing to Clay**

This collection records a creative Ganesh Chaturthi journey through drawing, clay modelling, work-in-progress moments, the finished sculpture and the artist with the completed work.

## Planned works

1. **Ganesha in Colour** — crayon / colour drawing
2. **Making Bappa** — clay sculpture process photographs
3. **Clay Ganesha — Work in Progress** — close-up of the developing sculpture
4. **Ganesh Chaturthi 2026** — finished clay Ganesha with floral decoration
5. **The Artist and Bappa** — portrait with the completed sculpture

## Archive principle

Keep both the artwork and selected process photographs. The purpose of this gallery is not only to show finished pieces, but also to preserve how each work was made.
